
I have initialized a new AstroJS project. Use the Astro docs MCP, Tailwind CSS v4 docs, and web-design-guidelines skills for creating the website. Also use the @DESIGN.md file and follow a clean, minimal design inspired by Apple.

Name: Temporizador Online
Domain: meutemporizadoronline.com

Create a simple, fast, modern online timer website where users can instantly create and use countdown timers directly in the browser. The primary experience should be extremely simple: users should be able to set a duration and start the timer within seconds, without registration or unnecessary configuration.

The website should be optimized primarily for Brazilian Portuguese users and use natural Brazilian Portuguese throughout the UI, page titles, labels, buttons, metadata, and SEO content.

### Core Timer

Build a highly polished countdown timer with:

* Large, highly readable timer display
* Hours, minutes, and seconds
* Start / pause / resume
* Reset
* Add time while running
* Subtract time while running
* Quick duration presets
* Custom duration input
* Countdown accuracy based on timestamps rather than interval accumulation
* Continue accurately when the browser tab is inactive
* Overtime mode after reaching zero
* Optional automatic stop or continue counting after zero
* Visual completion animation
* Sound notification when the timer finishes
* Test sound button
* Multiple sound options
* Mute/unmute
* Browser notification support where available
* Mobile vibration where supported

### Quick Presets

Provide convenient one-click presets such as:

* 1 minuto

* 10 minutos
* 15 minutos
* 20 minutos
* 25 minutos
* 30 minutos
* 45 minutos
* 60 minutos

Also allow users to create their own custom presets.

### Timer Modes

Support multiple timer modes:

1. Temporizador
2. Cronômetro
3. Pomodoro
4. Temporizador de Intervalos
5. Temporizador de Meditação

The mode selector should remain simple and unobtrusive.

### Pomodoro

Create a dedicated Pomodoro mode with:

* Focus duration
* Short break
* Long break
* Number of rounds
* Automatic transition between focus and break
* Current round indicator
* Pause / resume
* Skip current phase
* Reset session
* Optional sound notifications

Use sensible defaults such as 25 minutes focus and 5 minutes break while allowing customization.

### Interval Timer

Create an easy-to-use interval timer for workouts, HIIT, Tabata, boxing, stretching, and other activities.

Support:

* Work duration
* Rest duration
* Number of rounds
* Countdown before starting
* Automatic work/rest transitions
* Current round / total rounds
* Skip phase
* Pause / resume
* Reset
* Sound alerts
* Optional final countdown

Make the configuration significantly simpler and more polished than traditional interval timer interfaces.

### Timer Sequences

Add support for multi-step timer sequences.

Users should be able to create a sequence such as:

Warm-up — 5:00
Exercise — 3:00
Rest — 1:00

Rest — 1:00
Cool down — 5:00

Allow users to:

* Add steps
* Remove steps
* Reorder steps
* Give each step a name
* Set duration for each step
* Choose optional sounds
* Save sequences locally
* Start the complete sequence
* Skip a step
* Pause/resume
* Reset

This should be one of the website's useful differentiating features.

### Browser Tab Experience

While a timer is running:

* Update the browser tab title with the remaining time
* Update the favicon where practical
* Make it easy for users to monitor the timer while using another browser tab

Example:

"09:32 — Temporizador Online"

When the timer finishes, clearly indicate that the timer has ended.

### Screen Wake Lock

Support the browser Screen Wake Lock API where available.

Add an option such as:

"Manter tela ligada"

This should help prevent the device screen from turning off while a timer is running.

Gracefully handle browsers that do not support this feature.

* Recent timers

The website should work immediately without registration.

### Technical Requirements

Use AstroJS for the application.

Use Tailwind CSS v4.

Prefer client-side functionality and browser APIs wherever possible.

Avoid unnecessary backend infrastructure for features that can work locally.

Use TypeScript with clean, maintainable component architecture.

Keep JavaScript lightweight.

Optimize for:

* Fast initial load
* Minimal JavaScript
* Excellent Core Web Vitals
* Mobile performance
* Accessibility
* SEO
* Offline functionality

The timer must remain accurate and reliable.

Use timestamp-based calculations rather than relying on setInterval alone for elapsed-time accuracy.

Keep the codebase modular so additional timer modes and features can be added later.
